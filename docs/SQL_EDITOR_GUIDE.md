# Руководство по SQL редактору

## 🎯 Основные возможности

### 1. Подсветка синтаксиса (QTextEdit + QSyntaxHighlighter)

Редактор использует **QTextEdit** с кастомной подсветкой синтаксиса через **QSyntaxHighlighter**.

**Цветовая схема:**
- 🔵 **Ключевые слова** - синий (#569CD6)
- 🟠 **Строки** - оранжевый (#CE9178)
- 🟡 **Числа** - жёлтый (#D7BA7D)
- 🟢 **Функции** - зелёный (#DCDCAA)
- ⚫ **Комментарии** - серый (#808080, курсив)

### 2. Автодополнение на основе схемы БД

#### Ключевые слова SQLite
Редактор автоматически предлагает все ключевые слова SQLite:
- `SELECT`, `FROM`, `WHERE`, `AND`, `OR`, `NOT`
- `INSERT INTO`, `VALUES`, `UPDATE`, `SET`, `DELETE FROM`
- `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`
- `JOIN`, `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`
- `GROUP BY`, `ORDER BY`, `HAVING`, `LIMIT`, `OFFSET`
- `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- `BEGIN`, `COMMIT`, `ROLLBACK`
- И многие другие...

#### Таблицы и колонки
После открытия базы данных редактор загружает схему БД и предлагает:
- **Имена таблиц**: `users`, `orders`, `products`
- **Имена колонок**: `users.name`, `users.email`, `orders.total`

#### Как использовать:
```
1. Откройте базу данных
2. Начните вводить запрос
3. Нажмите Ctrl+Space
4. Выберите нужный элемент из списка
```

**Пример:**
```sql
SELECT users.name, users.email 
FROM users 
WHERE users.email LIKE '%@example.com'
     ↑
     Ctrl+Space покажет все колонки таблицы users
```

### 3. История запросов

#### Сохранение истории
- **Максимум записей**: 100 последних запросов
- **Хранение**: файл `logs/query_history.json`
- **Информация**: текст запроса, timestamp, статус (успех/ошибка), количество строк

#### Поиск по истории
1. Нажмите кнопку "📜 История"
2. Введите поисковый запрос
3. История отфильтруется в реальном времени
4. Двойной клик на запрос загрузит его в редактор

#### Управление историей
- **Обновить** - перезагрузить список
- **Очистить историю** - удалить все записии
- Автоматическое удаление старых записей при достижении лимита

### 4. EXPLAIN QUERY PLAN

#### Что это?
**EXPLAIN QUERY PLAN** показывает как SQLite выполняет ваш запрос:
- Использует ли индексы
- Полные сканирования таблиц
- Порядок JOIN операций
- Фильтрация и сортировка

#### Как использовать:
1. Введите SQL запрос
2. Нажмите "📋 EXPLAIN QUERY PLAN"
3. В диалоге увидите план выполнения

#### Пример вывода:
```
План выполнения запроса:
==================================================

  → SCAN TABLE users
  → SEARCH TABLE orders USING INDEX idx_orders_user_id (user_id=?)

==================================================

Советы по оптимизации:
- Используйте INDEX для больших таблиц
- Избегайте SELECT *
- Используйте WHERE для фильтрации
```

#### Интерпретация:
- **SCAN TABLE** - полное сканирование таблицы (медленно)
- **SEARCH TABLE USING INDEX** - использование индекса (быстро)
- **USING INDEX** - конкретный индекс используется

#### Советы по оптимизации:

**1. Создавайте индексы для часто используемых колонок:**
```sql
-- Медленно: полное сканирование
SELECT * FROM users WHERE email = 'test@example.com';

-- Создайте индекс
CREATE INDEX idx_users_email ON users(email);

-- Быстро: использует индекс
SELECT * FROM users WHERE email = 'test@example.com';
```

**2. Избегайте SELECT *:**
```sql
-- Неэффективно: загружает все колонки
SELECT * FROM users;

-- Эффективно: только нужные колонки
SELECT name, email FROM users;
```

**3. Используйте WHERE для фильтрации:**
```sql
-- Неэффективно: загружает всё и фильтрует в приложении
SELECT * FROM orders;

-- Эффективно: фильтрация в БД
SELECT * FROM orders WHERE total > 1000;
```

### 5. Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F5` | Выполнить запрос |
| `Ctrl+Enter` | Выполнить запрос |
| `Ctrl+Space` | Автодополнение |
| `Tab` | Вставить отступ (4 пробела) |
| `Shift+Tab` | Убрать отступ |

### 6. Интерфейс

#### Панель инструментов
- **▶ Выполнить (F5)** - выполнить текущий запрос
- **📋 EXPLAIN QUERY PLAN** - показать план выполнения
- **💡 Автодополнение (Ctrl+Space)** - вручную показать дополнения
- **📜 История** - открыть диалог истории запросов
- **🗑 Очистить** - очистить редактор

#### Редактор
- **Номера строк** - слева
- **Подсветка текущей строки** - текущая строка выделена
- **Автоматические отступы** - для правильной структуры
- **Edge column** - вертикальная линия на 120 символах

## 🎨 Настройка цветов

Цветовая схема настроена для комфортной работы в тёмной теме:

```python
# В functions/sql_editor.py - класс SQLLexer
self.setColor(QColor("#569CD6"), 1)    # Ключевые слова
self.setColor(QColor("#CE9178"), 2)    # Строки
self.setColor(QColor("#D7BA7D"), 4)    # Числа
self.setColor(QColor("#808080"), 9)    # Комментарии
```

## 📊 Примеры использования

### Пример 1: Выборка с автодополнением
```sql
-- Откройте базу данных с таблицей users
-- Начните вводить:
SELECT u.
-- Нажмите Ctrl+Space
-- Выберите: users.name, users.email

-- Продолжите:
FROM users u
WHERE u.email LIKE '%@example.com'
ORDER BY u.name
LIMIT 100
```

### Пример 2: Оптимизация запроса
```sql
-- Проверьте план выполнения
EXPLAIN QUERY PLAN
SELECT * FROM orders WHERE user_id = 123;

-- Если видите SCAN TABLE, создайте индекс
CREATE INDEX idx_orders_user_id ON orders(user_id);

-- Проверьте снова - должно быть USING INDEX
EXPLAIN QUERY PLAN
SELECT * FROM orders WHERE user_id = 123;
```

### Пример 3: Работа с историей
```
1. Выполните несколько запросов
2. Нажмите "📜 История"
3. Введите "SELECT" в поиск
4. Выберите нужный запрос из истории
5. Запрос загрузится в редактор
```

## 🐛 Возможные проблемы

### Ошибка подсветки синтаксиса
```
Решение: Перезапустите приложение
```

### Автодополнение не работает
1. Проверьте что база данных открыта
2. Нажмите Ctrl+Space вручную
3. Проверьте логи в `logs/app.log`

### История не сохраняется
1. Проверьте права записи в папку `logs/`
2. Проверьте что файл `logs/query_history.json` не заблокирован
