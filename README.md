## О проекте

SQLite Table Viewer - приложение для просмотра и редактирования SQLite баз данных. Позволяет просматривать .db файлы, выполнять SQL запросы, импортировать/экспортировать данные.

### Возможности

- Открытие баз данных (.db, .sqlite, .db3)
- Виртуальная прокрутка таблиц - постраничная загрузка (миллионы записей без нагрузки на память)
- Редактирование ячеек и строк (добавление/удаление строк и колонок)
- Поиск по таблице по всем колонкам
- SQL редактор с подсветкой синтаксиса, автодополнением, историей запросов, EXPLAIN QUERY PLAN
- Импорт из CSV и JSON
- Экспорт в CSV, JSON, Excel, PDF
- Инструменты: резервное копирование, оптимизация БД (VACUUM)
- Асинхронные операции в фоновых потоках с индикаторами прогресса и отменой
- Кэширование схемы таблиц

## 🚀 Установка

### Предварительные требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Пошаговая установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/yourusername/sqlite-table-viewer.git
cd sqlite-table-viewer
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустите программу:**
```bash
python main.py
```

## Использование

1. `Файл → Открыть базу данных` (Ctrl+O)
2. Двойной клик по таблице в левой панели
3. Просмотр данных с поиском, пагинацией, сортировкой
4. Переключитесь на вкладку "SQL запросы" для SQL редактора
5. Используйте кнопки панели инструментов для добавления/удаления строк и колонок

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Ctrl+O` | Открыть базу данных |
| `Ctrl+N` | Создать новую БД |
| `Ctrl+F` | Поиск в таблице |
| `F5` / `Ctrl+Enter` | Выполнить SQL запрос |
| `Ctrl+Space` | Автодополнение SQL |

### Цветовая схема

- Основной акцент: Красный (#ff4444, #8b0000)
- Выделение: Синий (#003366)
- Фон: Тёмные оттенки (#1a1a1a, #2d2d2d, #0d0d0d)

## Работа с большими данными

- Постраничная загрузка (50-1000 строк на страницу, по умолчанию 100)
- Автоподгрузка при прокрутке к концу страницы
- SELECT в фоновом потоке с индикатором прогресса и отменой
- Импорт/экспорт больших файлов чанками (по 10,000 записей)
- Кэширование схемы таблиц, страниц (до 20 страниц в кэше)
- Ограничения: Excel — 1M записей, PDF — 10K записей

## Интерфейс

**Левая панель:** список таблиц с количеством записей, информация о БД (имя, размер)

**Правая панель (вкладки):**
1. Просмотр таблицы — данные, поиск, пагинация, редактирование
2. SQL запросы — редактор с подсветкой, автодополнение, EXPLAIN QUERY PLAN
3. Графики — визуализация данных: столбчатые, линейные, круговые, точечные диаграммы и гистограммы

**Панель управления таблицей:**
- Поиск, лимит страницы, обновление
- Режим правки ячеек (✏️)
- Добавление/удаление строк (➕/➖)
- Добавление/удаление колонок (➕/➖)
